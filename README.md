# 🏨 Hotel Brilhante

Official website for **Hotel Brilhante**, a hotel located in Itacarambi, Minas Gerais, Brazil.

This project was developed to provide a modern, responsive, and user-friendly online presence for the hotel, including information about accommodations, services, contact details, and reservations.

## 🚀 Features

* 📱 Responsive design for desktop, tablet, and mobile
* 🏨 Hotel and accommodation information
* 📅 Reservation system
* 💬 WhatsApp integration
* 📍 Contact and location information
* 🔎 SEO optimization
* ⚡ Performance optimization

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Git & GitHub
* GitHub Pages
